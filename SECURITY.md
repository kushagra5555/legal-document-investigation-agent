# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Contact the maintainer privately through the GitHub profile instead.

Never include API keys, confidential legal documents, CVs, investigation traces, or generated evidence in an issue or pull request.

## Data handling

Local `.env` files, uploaded documents, PDFs, temporary traces, logs, and virtual environments are excluded from version control. Rotate any credential that may have been exposed and report the incident privately.
